# 模型卡：DKD 风险筛查模型

## 模型身份

- 版本：`0.1.0`
- 入选模型：`random_forest`
- 用途：基于常规体检信息的肾损伤标志物风险筛查原型。
- 禁止用途：临床诊断、处方、治疗决策或紧急分诊。

## 输入

age, HbA1c, diabetes_duration, systolic_bp, diastolic_bp, total_cholesterol, triglycerides, HDL, glucose, uric_acid, gender

`UACR`、`eGFR`、`serum_creatinine` 被明确排除，避免用构造标签的肾脏指标预测标签本身。

## 数据划分

- 训练：2011-2012, 2013-2014, 2015-2016
- 留出测试：2017-2018, 2017-2020
- 阈值：0.205（训练集内交叉验证预测确定）

## 留出测试集表现

| 指标 | 数值 |
|---|---:|
| ROC-AUC | 0.612 |
| PR-AUC | 0.307 |
| Brier score | 0.167 |
| 灵敏度 | 0.568 |
| 特异度 | 0.580 |

## 已知限制

1. 数据为横断面整理数据，不能解释为对未来 DKD 发病的纵向预测。
2. DKD 标签与常见 UACR/eGFR 阈值规则有 16 条记录不一致，必须追溯标签生成规则。
3. 测试 ROC-AUC 处于有限水平；客户端只能称为研究性风险筛查，不能使用诊断性措辞。
4. 训练数据来自 NHANES 背景，不代表模型已在中国人群中验证。
5. 缺失输入由训练期中位数/众数规则处理；客户端应提醒用户补齐体检数据。
