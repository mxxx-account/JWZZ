# 8 分钟项目演示脚本

准备：启动后端、前端和 MySQL（可选 Redis），打开 `http://localhost:3000`；另备一个 Edge 无痕窗口。使用测试邮箱，不用真实体检资料。医生演示账号与本地密码见[消息页验收](messages-acceptance.md)。

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 0:00–0:45 | 首页注册演示用户并登录 | React/Next.js 页面、Spring Security 会话与 CSRF；“不是诊断”边界 |
| 0:45–1:45 | 录入一组血压演示值（如 130/80），展开指标说明 | 单位、测量条件和年龄一并保存；输入范围是校验范围而非健康结论 |
| 1:45–2:30 | 在“最近录入”生成报告，再重复点击一次 | 同一 `entryId` 返回同一报告 ID；报告快照记录规则版本 |
| 2:30–3:30 | 展示趋势和报告、医生科室筛选；选心血管内科演示医生并授权 | 科室提示是导航，不是诊断；授权逐份报告生效 |
| 3:30–4:20 | 留空问题提交咨询并进入“消息” | 自动问候、目标医生会话、未读计数、左右双栏布局 |
| 4:20–5:20 | 无痕窗口登录目标医生，打开消息、接单、发送演示回复 | SQL 条件更新保证只有一个接单者；异步轮询而非实时问诊 |
| 5:20–6:10 | 用户端查看回复，再发一条消息 | 持续对话与已读游标；医生仅能访问被授权的报告 |
| 6:10–6:50 | 用户撤销授权；医生页面刷新 | 医生报告和会话消失，接口层同样拒绝继续发送 |
| 6:50–8:00 | 打开架构图、数据库图和测试报告 | 说明单体/事务/唯一键/Redis 取舍；展示 1 与 60 份报告的压测差异以及分页改进方向 |

备选演示：如果现场服务不可用，可展示 `mvn test`、`./scripts/verify_stage5.ps1`、`./scripts/verify_messages.ps1`、`npm run test:e2e` 的记录和测试报告。不要演示真实医疗建议、真实用户资料、下单或在线坐诊。面试提问时明确区分“已运行通过”“仅代码设计”“未来计划”。
