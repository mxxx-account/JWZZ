# 用户首页侧栏工作区验收

## 改动与原因

用户首页改为固定侧栏加单一内容工作区。四个入口仍是“录入体检指标”“最近录入”“同类指标趋势”“我的报告与授权”，但一次只显示一个模块，避免页面随着报告增长而无限拉长。窄屏时侧栏变为顶部双列入口。

报告区默认每页 12 份，只请求编号、类别、标题、生成时间等摘要；选中报告后才请求完整快照、该报告授权和咨询。可按报告编号、指标类别、起止日期查找，选择“最早优先”快速到达第一份报告，或用上一页／下一页浏览。点击“清空筛选”恢复全部。服务端始终按当前登录用户限定查询，前端筛选不是权限边界。报告科室提示另外读取每个类别的最新一份报告，不再加载全部报告。

“最近录入”点击生成报告后会跳转报告区并按新生成的报告编号定位；侧栏再次进入报告区则显示全部报告。报告详情仍可选科室与在线状态、按医生邮箱授权、撤销授权、提交咨询、进入已有咨询。消息页和医生端未改动。

## 手工验收步骤

1. 按 `docs/development.md` 启动 MySQL、后端和前端。用用户账号登录，确认首页左侧有四个入口，默认显示“录入体检指标”。
2. 录入一组血压值并保存，切换“最近录入”，生成报告。确认自动进入“我的报告与授权”，左侧列表定位到该报告，右侧出现完整报告。
3. 清空筛选，改用类别、日期、编号和“最早优先”分别查找；有多份报告时用分页确认旧报告仍能访问。无结果时显示明确提示。
4. 选择报告，测试推荐科室、在线/离线筛选、医生邮箱授权、撤销授权、提交咨询并跳到消息页；医生端接受并回复，用户消息页可收到回复。
5. 将浏览器宽度缩至约 390px，确认四个入口可点击、报告筛选与详情不横向溢出。
