# 报告解读与咨询准备 Agent：阶段一验收

本阶段交付血压报告的只读事实接口：从报告快照取本次数值，按本次**测量时间**查本人最近一条同条件、可验证的历史记录，并在后端计算差值。未改前端、授权和咨询流程，未调用模型，未新增数据库迁移。

## 一键验收

启动本机 MySQL，确认项目的 `server/.env.local.ps1` 已配置。在项目根目录打开 PowerShell：

```powershell
.\scripts\verify_agent_stage1.ps1
```

不需要启动前端或后端，不需要 Redis 和模型账号。脚本用现有 Maven 缓存离线运行。测试通过 Spring MVC 的请求链登录并访问新接口，连接真实本机 MySQL；账号、授权和指标均为虚构数据，按测试事务回滚。通过时查看 `Tests run: 5, Failures: 0, Errors: 0, Skipped: 0` 与 `BUILD SUCCESS`；详细结果在 `server/target/surefire-reports/com.jwzz.server.report.ReportEvidenceIntegrationTest.txt`。

如需一起运行原有后端测试，执行 `.\scripts\verify_agent_stage1.ps1 -Full`。

开发验证记录（2026-11-11）：本机 MySQL 8.0.46，Flyway 校验 V1–V12、无待执行迁移。完整后端回归 32 项通过（含本阶段 5 项），无失败、错误或跳过；单独运行验收脚本再次通过 5 项，测试后虚构账号残留为 0。

| 验收场景 | 预期 |
| --- | --- |
| 打开 1 月 5 日的旧居家报告：此前有 1 月 2 日居家记录、1 月 3 日门诊记录，之后还有新居家记录 | 取 1 月 2 日；同一时刻、未来记录和其他用户的记录不参与 |
| 本次 129.5001 / 76，对比 122.25 / 78（虚构数值，单位 mmHg） | 收缩压差值 +7.2501、舒张压差值 -2；修改测试中的原始来源记录不改变当前报告快照 |
| 缺项、不同录入只有各一项、单位不匹配、转换版本未确认或同一次录入有重复项 | 跳过不可靠的记录；没有可比历史时仅返回本次事实，不返回差值 |
| 仅有一条记录、血糖报告、旧版快照 | 分别返回「无可比历史」「分类暂不支持」「快照暂不支持」 |
| 匿名、其他用户、商家、已获得原报告授权的医生 | 分别返回 401、404、403、403；医生仍可读取已授权的原报告 |

## 用浏览器亲自核对接口（可选）

按[本地开发说明](development.md)启动新版后端和前端，用自己的**测试用户**登录。录入两次时间不同的虚构居家血压，为较晚的录入生成报告。在「我的报告与授权」找到报告编号，把下方地址中的 `123` 换成这个编号后在同一浏览器打开：

```text
http://localhost:8080/api/reports/123/assistant/evidence
```

用与前端配置相同的后端主机名，例如不要把 `localhost` 和 `127.0.0.1` 混用。浏览器会显示 JSON；有可比历史时状态为 `AVAILABLE`，`current` 是本次记录、`previous` 是上次同条件记录、`change` 是本次减上次。可再录入一条时间更晚的记录，刷新旧报告接口，确认它仍引用原来的历史记录。

## 接口与指标词典

- 接口：`GET /api/reports/{reportId}/assistant/evidence`。不接收用户 ID 或报告正文。身份来自现有登录会话；数据库按报告编号和用户 ID 一起查找。响应为 `Cache-Control: no-store`。
- 字段：`reportId`、`status`、`indicators`、`current`、`previous`、`change`、`notice`。无结果的读数及差值为 `null`，不是 0。
- 词典：`systolic_bp`（收缩压）、`diastolic_bp`（舒张压），两者单位均为 `mmHg`；`HOME` 为居家、`CLINIC` 为门诊。词典不含临床阈值。
- 历史候选的两项血压必须来自同一次录入，时间和条件一致，单位已验证；整条历史记录必须早于本次快照，并与本次的测量条件相同。多个合格历史候选时间完全相同时，选择后入库的一条。
- 状态：`AVAILABLE`（有可比历史）、`NO_COMPARABLE_HISTORY`（保留本次记录）、`UNSUPPORTED_CATEGORY`（目前仅血压）、`UNSUPPORTED_SNAPSHOT`（旧版、缺字段或无法确认单位等）。
