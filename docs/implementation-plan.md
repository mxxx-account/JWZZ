# 第一版实施清单

## 范围

用户录入血压、血糖、血脂数据；系统按有来源、可版本化的规则生成指标解读和历史趋势；医生演示账号仅查看用户明确授权的报告并回复演示咨询。旧 DKD 模型独立保留，暂不用于面向用户的疾病概率预测。

- [x] 保留已有模型、报告和 Electron 原型；不覆盖原始 CSV
- [x] 明确新版目录和项目定位
