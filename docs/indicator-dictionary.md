# 指标数据字典（第一版草案）

此文件定义应用输入和存储约束，不定义疾病诊断阈值。具体解读规则须有来源、版本、适用人群和复核记录后再启用。

| 编码 | 中文名称 | 标准单位 | 必要上下文 | 展示方向 |
|---|---|---|---|---|
| `systolic_bp` | 收缩压 | mmHg | 测量日期、时间、是否居家测量 | 与舒张压一起展示趋势 |
| `diastolic_bp` | 舒张压 | mmHg | 与收缩压同次测量 | 与收缩压一起展示趋势 |
| `blood_glucose` | 血糖 | mmol/L | 空腹、餐后或随机；餐后需说明时间 | 同类型记录比较 |
| `hba1c` | 糖化血红蛋白 | % | 检测日期 | 单独展示趋势 |
| `total_cholesterol` | 总胆固醇 | mmol/L | 检测日期 | 血脂组趋势 |
| `ldl_cholesterol` | 低密度脂蛋白胆固醇 | mmol/L | 检测日期 | 血脂组趋势 |
| `hdl_cholesterol` | 高密度脂蛋白胆固醇 | mmol/L | 检测日期 | 血脂组趋势 |
| `triglycerides` | 甘油三酯 | mmol/L | 检测日期 | 血脂组趋势 |

阶段 3 已实现按一次录入生成 `entry_id`，同组指标共享测量时间和条件。数据库同时保存用户输入的原始数值与单位、标准化后的数值与单位、换算规则版本 `units-2026-01`、测量时年龄及妊娠状态，避免单位转换后丢失原始报告信息。旧版记录在 V2 迁移中标为 `legacy-unverified`，不得当作可靠换算结果。单次数据只能作为一次记录；报告措辞不得由单次输入直接推断确诊结果。

目前规则是 Java 中的研发草案，不是已审核临床规则；返回规则编码、版本、适用条件、解释、来源标题与链接及 `AWAITING_CLINICAL_REVIEW` 状态。只有本地 `dev` 配置会在保存响应和报告快照中包含预览，正式配置不返回阈值解读。阶段 4 已保存报告生成时的规则版本与内容快照；正式启用前仍需临床顾问确认规则生效日期、审核人及审核记录。
